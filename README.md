# Flappy Bird
Segundo videojuego para la materia programación de videojuegos donde implementaremos modos de juego, powerups,
modos de pausa, etc.

# Instalacion y ejecución:
Crea un entorno virtual donde instalar las dependencias y desde ahí ejecutar el juego.
1. Entorno virtual:
```
python3 -m venv .venv
source .venv/bin/activate       # On Windows: .venv\Scripts\activate
```
2. Instalar dependencias:
```pip install -r requirements.txt```

3. Ejecutar:
```python3 main.py```
